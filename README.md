# CU.ByMark

A lightweight Android unit converter app by Mark. Quickly switch between temperature (°C/°F/K), length (m/ft/in), and mass (kg/lb/oz) with a clean interface. Input a value, pick your units, and get instant conversions, bidirectional and hassle-free.

### Tools
*   Android Studio Meerkat | 2024.3.1 Patch 2
*   Gradle: 8.11.1
*   Git:  version 2.47.1
*   JDK:  version 17.0.14
*   Vim: version  9.1
*   Gemini

### Tech Stack
*   Kotlin
*   Kotlin Coroutines
*   Jetpack Compose
*   Material 3
